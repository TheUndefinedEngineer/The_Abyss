- They are used to get access to the debug interface of the target with native protocol signalling such as SWD or JTAG since HOST doesn't support such interfaces.
- It does protocol conversion. For example, commands and messages coming from host application in the form of USB packets will be converted to equivalent interface signalling (SWD or JTAG) and vice-versa.
- Mainly debug adapters help to download and debug the code.
- Some advanced debug adapters will also help to capture trace events such as on the fly instruction trace and profiling information.
